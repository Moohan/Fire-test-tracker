## 2026-05-12 - [Skeleton Loaders for PWAs]
**Learning:** For mobile-first PWAs like SFRS ETT, perceived performance is critical. Replacing static "Loading..." text with skeleton loaders that mimic the actual UI structure significantly improves the user's perception of speed and provides a more professional, "app-like" experience.
**Action:** Always prefer skeleton loaders over simple text or spinner loading states for main dashboard/list views to maintain UI stability during data fetching.
